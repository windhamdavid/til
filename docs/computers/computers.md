## Notes

My first computer was a Commodore 64 in 1983 and my second was an Apple IIc in 1984 ( see - [https://davidwindham.com/shall-we-play-a-game/](https://davidwindham.com/shall-we-play-a-game/) ). I had a Dell Windows 3.1/95 laptop cin college and then a Sony VAIO picturebook running Windows 98. The 2003 Apple Powerbook got me back into computers and started paying the bills. My 2006 Macbook Pro was named 'Silver Bullet' and I've since named them all. I've started lumping leased client and personal servers into the mix too. I now keep documentation on each of them to help the weakest link in the chain which seems to be my brain. 

## Workflow

I've noticed that I can get about seven years out of each machine and I've worked out a workflow that makes it relatively seamless. It took me years of mistakes to figure out what works, but I've relied on the 100% mathematical probability that a computer will fail as my guiding priciple. I've never lost any data ever ( knock on wood ), but I don't have a digital hording problem either and most of it is fairly organized. 

### Backups 

When a computer is retired, I drop the user files into an archive on portable drive under the computer name even though a good chunk of them are moved in the migration. 

### Convention

I now use the exact same file structure for everything and I try to use a consistent file naming conventions. Every computer and server is set up the same way only making minor improvements or changes on upgrades. 

### Personal

I'm all in on the Apple ecosystem and using enabling iCloud storage has just made syncing documents, photos, and email so much more simple. It's also made computer upgrades easy. I also like to recycle the old machines now too so I just trade em in on the upgrades. 

### Servers

I used to think that configuring servers was fun and I'd usually learn some new trick for everyone I set up. I now wire up my provider APIs and let my desktop run the setups from scripts because automation is more fun.
