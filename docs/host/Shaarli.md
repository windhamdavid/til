# Shaarli

[davidwindham.com/bookmarks](https://davidwindham.com/bookmarks/)

I use Shaarli as a bookmarking service that syncs with my [Feed Reader](/docs/host/Miniflux) and feeds the bookmarks on my [archive page](https://davidwindham.com/archive). I've used it for about ten years now and the database stays really small.
